# GBECHE - Spécifications Techniques et Fonctionnelles (PRD) ## 1. Vision du Projet GBECHE est une application de discipline personnelle "offline-first". Elle transforme la gestion de vie en une stratégie militaire : les domaines sont des **Guerres**, les objectifs des **Batailles** et les tâches des **Adversaires**. Un agent IA local (LLM on-device) sert de mentor et d'assistant de saisie. ## 2. Stack Technique (Choix Judicieux) - **Framework :** React Native + Expo (vitesse de dev, accès natif). - **Build Tool :** Vite (via Expo Router). - **Styling :** TailwindCSS (via NativeWind) pour la rapidité et la consistance. - **Base de données :** **WatermelonDB**. Pourquoi ? C'est une DB relationnelle hautement performante pour React Native, capable de gérer des milliers d'entrées sans ralentir l'UI. - **Local AI :** Utilisation de bibliothèques comme `react-native-llama` ou des modèles ONNX compressés (ex: Phi-2 ou Mistral 7B Tiny) pour le traitement NLP offline. - **Package Manager :** `pnpm` (efficace et rapide). ## 3. Schéma de la Base de Données (Relations) - **Wars (Domaines) :** id, title, icon, color, type (Finance, Santé, etc.) - **Battles (Objectifs) :** id, war_id, title, deadline, status. - **Adversaries (Tâches) :** id, battle_id, title, frequency, scheduled_at, completed_at, status (Won/Lost). - **Accounts (Finances) :** id, name (Momo, Cash, etc.), balance. - **Transactions :** id, account_id, amount, type (Income/Expense), category, timestamp. - **TimeLogs :** id, activity_name, start_time, end_time, is_planned. ## 4. Liste des Écrans (Ordre de Création) 1. **Onboarding (5 étapes) :** Manifeste, Sécurité (FaceID), Initialisation Finances, Première Guerre, Pacte de Discipline. 2. **Dashboard "Quartier Général" :** Vue d'ensemble, graphes de performance globale, prochaines batailles. 3. **Calendrier / Tracking :** Visualisation heure par heure, détection des "trous", validation des tâches. 4. **Finance "Trésorerie" :** Gestion des comptes, saisie de dépenses, budgets, graphes de répartition. 5. **Guerres (Détails par Domaine) :** Graphes spécifiques (Radar pour santé, Deep Work pour Pro). 6. **Chat IA "L'Agent" :** Interface de dialogue pour saisie naturelle et conseils. ## 5. Guide pour le Développeur Junior - **Installation :** `npx create-expo-app Gbeche -t expo-template-blank-typescript` puis configurer `pnpm`. - **Configuration WatermelonDB :** Créer le schéma, les modèles et connecter le provider à la racine. - **Sécurité :** Utiliser `expo-local-authentication`. - **UI/UX :** Appliquer `backdrop-filter: blur()` pour le Glassmorphism. Utiliser `Lottie` pour les animations de "Guerre". ## 6. Algorithme de Réajustement (UC 4) Chaque soir à 23h : 1. Scanner les `Adversaries` du jour non complétés. 2. Vérifier les `TimeLogs` vides du lendemain. 3. Proposer une mise à jour des `scheduled_at` vers ces créneaux vides. GBECHE - Trésorerie
