## 1. PHILOSOPHIE : Pourquoi Duolingo retient ses utilisateurs (et comment on fait mieux)

Duolingo garde ses utilisateurs grâce à 4 leviers :
- **Streak** (peur de perdre)
- **Leagues** (comparaison sociale)
- **Lives/Hearts** (punition)
- **Notifications ciblées** (rappels au bon moment)

**Pourquoi GBECHE va plus loin :**

| Duolingo | GBECHE |
|----------|--------|
| Streak cassé = tout perdu | Shields gagnés par performance (pas achetés) |
| Apprendre une langue = fun mais pas vital | Disciplines de vie = conséquences réelles |
| Compétition anonyme | Territoires visuels avec invasion si tu abandonnes |
| Daily goal fixe | Boss hebdomadaire avec drama narratif |
| Motivation externe (badges) | Motivation interne (progresser dans sa vraie vie) |
| 100% gamifié = peut sonner creux | 100% ancré dans la réalité de l'utilisateur |

## 2. STRATÉGIE D'ONBOARDING (Convertir en 5 minutes)

### Étape 1 : Le Choc Émotionnel (0-30 secondes)
- Animation boussole → épée (Lottie) sur fond vide noir
- Phrase : *"Le chaos s'arrête ici."* (une seconde de silence)
- Puis : *"GBECHE n'est pas une app. C'est ton quartier général."*
- **Objectif** : créer une première impression qui marque

### Étape 2 : La Confiance (30-90 secondes)
- Bouclier animé qui pulse
- *"Pas de cloud. Pas de serveurs. 100% sur ton téléphone."*
- FaceID / PIN immédiatement demandé — ça renforce l'aspect "sécurité personnelle"
- **Psychologie** : l'utilisateur sent qu'on le respecte

### Étape 3 : Le Premier Investissement (90-180 secondes)
- Demander le solde de ses comptes (3 champs max)
- **Psychologie** : Endowment Effect — il a déjà quelque chose dans l'app
- Même si la valeur est petite, c'est "son argent" dans "son app"

### Étape 4 : La Première Victoire (180-240 secondes)
- Lui faire choisir sa première Guerre
- Lui faire créer un premier Adversaire (tâche simple pour demain)
- L'Adversaire est immédiatement créé → animation XP → `+50 XP`
- **Psychologie** : Biais d'investissement + victoire immédiate = il veut continuer

### Étape 5 : Le Pacte (240-300 secondes)
- Demander autorisation notifications
- Cadrer comme un contrat militaire : *"Je serai ton ombre."*
- **Psychologie** : Engagement volontaire → plus de compliance

## 3. BOUCLES DE RÉTENTION QUOTIDIENNES

### 🌅 Le Rituel du Matin (6h-8h)
**Notification** : *"Général, tes ordres de mission sont prêts. 3 adversaires t'attendent."*
- Ouvre sur le Dashboard avec les tâches du jour déjà prêtes
- Si tâche avant 9h → badge "Guerrier du Matin" + bonus XP 25%
- **Friction minimale** : 1 tap pour voir le planning

### ⚡ La Vérification de Midi (12h-13h)
**Notification** : *"Mi-journée. Tu en es où ?"*
- Micro-session : cocher 1 tâche = 30 secondes dans l'app
- **Psychologie** : Hook de Nir Eyal — trigger → action → reward → investment

### 🌙 Le Bilan du Soir (21h-22h)
**Notification** : *"Il reste 2 batailles. Veux-tu les reprogrammer demain ?"*
- Affiche un résumé visuel : tasks won/lost, XP gagné, streak status
- Proposition de réajustement → 1 tap = accepté
- **Psychologie** : Clôture de la Zeigarnik Loop (les tâches incomplètes restent en mémoire)

### 🏆 Le Boss du Dimanche (20h)
**Notification** : *"Le Boss hebdomadaire expire dans 3h. Tu peux encore le vaincre !"*
- FOMO contrôlé (peur de manquer quelque chose)
- Reward rare si victoire (avatar gear unlock)

## 4. MÉCANIQUES DE RÉTENTION AVANCÉES

### 4.1 Le Système de Streak (Mieux que Duolingo)

```
Règle GBECHE : Streak OK si ≥ 50% des tâches du jour faites
Duolingo     : Streak OK si session faite peu importe la qualité
```

- **Streak Shield** : gagné tous les 7 jours parfaits (pas acheté)
- **Streak Insurance** : si tu as 3 shields et tu rates, 1 shield consommé silencieusement
- **Streak Revival** : après 3 jours d'inactivité, offre de "Battle Comeback" avec défi pour récupérer le streak

**Visuellement** : La flamme grandit avec le streak
- 0-6 jours : petite flamme
- 7-29 jours : flamme normale
- 30-99 jours : flamme + particules
- 100+ jours : flamme dorée légendaire

### 4.2 Le Système de Territoire (Unique à GBECHE)

Chaque Guerre = un territoire sur une map.
- Territoire à 80%+ = animation de domination
- Territoire à 40%- = animation d'invasion (territoire envahi)
- **Psychologie** : Loss Aversion — perdre du territoire fait mal plus que gagner en fait plaisir

**Notifications de menace** :
*"⚠️ Ton territoire Santé est envahi ! 2 jours sans bataille..."*

### 4.3 Les Boss Battles Hebdomadaires

Chaque lundi : nouveau Boss
- Défi spécifique (20 tâches, tracker 7 jours, combo ×7, etc.)
- Deadline dimanche 23h59
- Reward rare : avatar gear, thème couleur, particule spéciale
- **Narration** : Le Boss a un nom, une "menace" visuelle → histoire

### 4.4 Le Système de Combo (Variable Ratio)

```
Combo ×2  → +20% XP
Combo ×3  → +50% XP  + son
Combo ×5  → +75% XP  + animation feu
Combo ×7  → +100% XP + son épique
Combo ×10 → +150% XP + tremblement écran + confettis
```

**Le random surprise bonus** : 15% de chance d'obtenir ×1.5 sur n'importe quelle tâche
→ C'est la mécanique de slot machine qui rend les jeux addictifs

### 4.5 Le Système de Prestige

Après le niveau 20 :
- Option de "Prestige" : reset au niveau 1 avec badge spécial
- XP conservé en "XP Total" affiché sur le profil
- Accès à couleurs exclusives, frames de profil
- **Psychologie** : Renouvellement du cycle + fierté sociale

## 5. STRATÉGIE DE RE-ENGAGEMENT

### Si l'utilisateur est absent 1 jour :
*"On a besoin de toi, Guerrier. Ton territoire se stabilise encore."* (pas d'accusation)

### Si absent 3 jours :
*"3 adversaires t'attendent. Ils ne mourront pas seuls."* (drama léger)

### Si absent 7 jours :
*"Ton streak est protégé par un shield. Reviens avant dimanche."* (FOMO)
→ Proposer une "Mission de Retour" simplifiée (1 seule tâche)

### Si absent 14 jours :
*"Battle Comeback disponible. 1 défi = ton streak retrouvé."*
→ Si le défi est fait, récupère X% du streak (jamais tout)

### Si absent 30 jours :
*"Que s'est-il passé sur le champ de bataille ?"*
→ Proposer un onboarding allégé (re-setup des priorités)
→ Créer un nouveau niveau de départ (pas revenir à 0 XP)

## 6. PSYCHOLOGIE DE L'INTERFACE

### 6.1 Principes UX appliqués

**Feedback immédiat** (< 100ms sur chaque action)
- Son + haptic + animation sur chaque check
- XP qui "vole" vers la barre en haut

**Célébrations mémorables**
- Journée parfaite → animation plein écran "VICTOIRE TOTALE"
- Streak milestone → photo-moment shareable (même offline)
- Level up → son épique + ring animé + shake léger

**Affordances claires**
- Aucune action à plus de 2 taps
- Agent IA accessible en 1 tap (bouton flottant)
- FAB "+" toujours visible pour créer vite

**Dark pattern éthique** : Completion gap
→ La barre XP est toujours montrée proche du prochain niveau
→ Jamais 0% au début, toujours 85%+ au démarrage de journée

### 6.2 Ton de la communication (copywriting)

| ❌ À éviter | ✅ GBECHE |
|------------|-----------|
| "Vous avez raté votre objectif" | "2 adversaires ont résisté aujourd'hui." |
| "Complétez votre profil" | "Ton quartier général est à 60%" |
| "Rappel : faire du sport" | "L'adversaire Cardio t'attend. Es-tu prêt ?" |
| "Bon travail !" | "Victoire. Territoire conquis. +150 XP." |
| "Vous êtes en retard" | "Le temps passe. Tes guerres n'attendent pas." |

### 6.3 Couleurs et émotions

- **Cyan** (#00E5FF) : focus, clarté, précision — pour les tâches Carrière
- **Vert** (#00FF88) : victoire, validation, santé — pour les succès
- **Orange** (#FF6B35) : énergie, urgence légère — pour les streaks
- **Rouge** (#FF4757) : danger, territoire en risque — jamais pour les erreurs "banales"
- **Or** (#FFD700) : récompense rare, achievement, prestige — toujours mérité
- **Violet** (#A78BFA) : XP, niveau, croissance personnelle — toujours présent
