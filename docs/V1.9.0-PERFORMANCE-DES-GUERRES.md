# GBECHE 1.9.0 — Voir quelle guerre tient, et laquelle décroche

> Deux ajouts, une seule idée : rendre la performance visible **là où tu agis**,
> et te le dire **une fois**, pas cinquante.

## 1. Bandeau de performance dans l'écran Guerres

Chaque guerre affiche désormais, directement sous son en-tête :

| Élément | Calcul |
| --- | --- |
| Taux de réussite | victoires / (victoires + défaites) sur 30 jours |
| Volume | `n V · n D · n ⏳` |
| XP | somme des XP **des seules victoires** |
| Évolution | écart de taux en points vs les 30 jours précédents |

La fonction `warPerformance()` réutilise **exactement** le moteur du Bilan
(`warBreakdownOf`) sur deux fenêtres consécutives. Une seule source de vérité,
donc aucun risque que l'écran Guerres et le Bilan racontent deux histoires.

Trois cas sont traités explicitement, sans chiffre trompeur :

- **Aucune mission planifiée** → « Aucune mission planifiée sur les 30 derniers jours. » (pas un 0 %).
- **Missions en attente seulement** → un tiret + « Aucune mission tranchée pour l’instant : termine-en une pour voir ton taux. »
- **Pas d'historique de comparaison** → « Pas de comparatif » au lieu d'un faux « +0 pts ».

Performance : l'écran charge 60 jours d'instances **une seule fois** et filtre
par guerre en mémoire, puis calcule les deux fenêtres sans nouvelle requête.

## 2. Alerte « guerre fragile »

Conditions **cumulatives** pour qu'un rappel apparaisse :

1. la guerre a le plus faible taux de réussite sur 30 jours ;
2. ce taux est **strictement inférieur à 50 %** ;
3. elle compte **au moins deux missions tranchées** (on ne juge pas sur une) ;
4. **aucune mission n'y est prévue aujourd'hui** ;
5. le rappel n'a pas déjà été émis aujourd'hui ;
6. le réglage « Alerte guerre fragile » est actif (par défaut : oui).

Choix de conception assumés :

- **Aucune notification système** pour ce cas : on ne réveille personne pour ça.
- **Un seul rappel par jour**, daté dans la table `settings` (clé/valeur) :
  aucune migration, aucun nouveau schéma.
- Le rappel est **cliquable** et ouvre l'écran Guerres.
- **Silence en cas d'erreur de lecture** : mieux vaut rien qu'un message faux.
- La date n'est écrite **que si le rappel est réellement émis** : si la
  situation se débloque avant, rien n'est verrouillé pour la journée.
- La base n'est **pas relue en boucle** : une évaluation par jour et par
  session (`evaluatedDay`), sinon le sondage de 30 s relancerait 3 requêtes
  toutes les 30 secondes pour rien.

## 3. Réglages

Nouvelle ligne dans **Réglages → Assistant** : « Alerte guerre fragile —
Un rappel par jour si une guerre décroche », avec interrupteur.

## 5. Ce qui reste volontairement dehors

- **Pas de bonus XP** quand une guerre est « sauvée » : règle de gamification
  non validée, donc non inventée.
- **Pas de notification poussée** pour l'alerte : décision ci-dessus.
- **Pas de seuil configurable par l'utilisateur** : 50 % est une valeur
  explicite et testée, ajustable plus tard si tu le demandes.
