## 🌟 Introduction & Vision

**GBECHE** est une application de gestion de discipline personnelle qu'on peut utiliser sur son téléphone **sans Internet**. Elle gamifie la vie en la transformant en une stratégie militaire :

- **GUERRES** = Domaines de vie (Finance, Santé, Professionnel, Spirituel, etc.)
- **BATAILLES** = Objectifs grands (Ex: "Créer un fonds d'urgence de 100.000 FCFA")
- **ADVERSAIRES** = Petites tâches (Ex: "Ajouter 5000 FCFA à mon épargne")

L'app fonctionne en 100% offline, protège ta vie privée (cryptage), et utilise une IA locale pour automatiser la saisie de tes activités.

### Philosophie
- **100% Offline** : Rien ne part sur le cloud. Tes données restent dans ton téléphone.
- **Privacy First** : Accès par FaceID, empreinte, ou code PIN.
- **Gamification** : Chaque tâche complétée = Victoire. Chaque échec = Défaite. Des graphes te montrent ta progression.
- **IA Locale** : Tu peux parler à l'app ("J'ai dépensé 5000 au coiffeur") et elle comprend.

## 🛠️ Stack Technique Expliquée

### Qu'est-ce que c'est ?

Pour construire GBECHE, on utilise plusieurs outils. Voici pourquoi chacun est choisi :

| Technologie | Quoi ? | Pourquoi ? |
|---|---|---|
| **React Native** | Framework pour créer des apps mobiles | Même code pour iPhone ET Android. Plus rapide qu'écrire deux apps séparées. |
| **Expo** | Framework par-dessus React Native | Simplifie tout. Pas besoin de Xcode/Android Studio. |
| **Vite** | Outil pour faire démarrer l'app rapidement | L'app charge plus vite en développement. |
| **TailwindCSS** | Système de design rapide | Crée une belle UI en 10x moins de code. |
| **WatermelonDB** | Base de données mobile | Super rapide. Peut gérer 10,000 tâches sans ralentir. |
| **expo-local-authentication** | Lecteur d'empreinte/FaceID | Protège l'app avec ton empreinte ou Face ID. |
| **expo-notifications** | Système d'alertes | T'envoie des notifications pour te rappeler de faire tes tâches. |
| **pnpm** | Gestionnaire de packages | Plus rapide et efficace que npm ou yarn. |
| **ONNX Runtime / react-native-llama** | IA locale | L'IA fonctionne **dans** le téléphone, sans Internet. |
| **react-native-chart-kit** | Graphes et courbes | Affiche tes statistiques de façon belle. |
| **Lottie** | Animations | Crée des animations fluides. |

### Qu'est-ce qu'un Framework ?

Un **framework** c'est comme une boîte à outils pré-faite.

- Sans framework : Tu construis une maison brique par brique.
- Avec framework : La charpente est déjà là, tu dois juste ajouter les portes et les fenêtres.

**React Native** = Charpente pour les apps mobiles.

### Qu'est-ce que c'est "Offline" ?

**Offline = Sans Internet.**

- ❌ Mauvais : L'app envoie tes données à un serveur dans le cloud.
- ✅ Bon : GBECHE garde tes données **dans ton téléphone**.

Avantage : Si tu es en avion, dans un métro, ou en brousse → L'app fonctionne toujours.

## 📋 Prérequis Système

Avant de commencer, assure-toi que tu as :

### Sur ton ordinateur

1. **Node.js** (version 18+)
   - C'est l'outil qui exécute JavaScript sur ton PC.
   - Télécharger : https://nodejs.org/
   - Vérifier : Ouvre Terminal/CMD et tape `node -v`
   - Résultat attendu : `v18.x.x` ou plus récent.

2. **pnpm** (le gestionnaire de packages)
   - C'est comme l'App Store du développement. Ça télécharge les librairies qu'on a besoin.
   - Installation : Ouvre Terminal/CMD et tape `npm install -g pnpm`
   - Vérifier : `pnpm -v` (doit afficher un numéro de version)

3. **Git** (Pour le contrôle de version)
   - Télécharger : https://git-scm.com/
   - Ça permet de "revenir en arrière" si on casse quelque chose.

### Sur ton téléphone

- **iPhone 13+** ou **Android 10+**
- L'app **Expo Go** (télécharger gratuitement sur l'App Store ou Google Play)
- C'est l'app qui te permet de tester en développement.

## 🚀 Installation Complète

### Étape 1 : Crée le Projet de Base

Ouvre Terminal/CMD dans le dossier où tu veux créer le projet :

```bash
# Crée une nouvelle app Expo avec TypeScript
npx create-expo-app@latest GBECHE --template expo-template-blank-typescript

# Entre dans le dossier
cd GBECHE
```

**Qu'est-ce qu'on vient de faire ?**
- `npx` = "Exécute ce programme téléchargé une fois"
- `create-expo-app` = L'outil qui crée le projet
- `GBECHE` = Le nom du dossier du projet
- `--template expo-template-blank-typescript` = Utilise TypeScript (plus sûr que JavaScript)

### Étape 2 : Remplace npm par pnpm

Par défaut, le projet utilise `npm`. On va utiliser `pnpm` (plus rapide) :

```bash
# Supprime les fichiers npm
rm -rf node_modules package-lock.json

# Crée un fichier de configuration pour pnpm
pnpm install
```

**Qu'est-ce qui s'est passé ?**
- `rm -rf node_modules` = Efface le dossier des librairies téléchargées.
- `pnpm install` = Retélécharge tout avec pnpm.

### Étape 3 : Installe les Dépendances Principales

```bash
# Base de données
pnpm add @nozbe/watermelondb

# Authentification (FaceID, empreinte)
pnpm add expo-local-authentication

# Notifications locales
pnpm add expo-notifications

# Système de fichiers (pour exporter les données)
pnpm add expo-file-system expo-sharing

# UI/Styling
pnpm add nativewind

# Graphes et statistiques
pnpm add react-native-chart-kit

# Animations
pnpm add lottie-react-native

# Navigation
pnpm add @react-navigation/native @react-navigation/bottom-tabs
pnpm add react-native-screens react-native-safe-area-context

# Gestion d'état (optionnel mais recommandé)
pnpm add zustand

# IA locale (optionnel pour le chat, version simplifiée d'abord)
# pnpm add react-native-llama  (À activer plus tard)
```

**Qu'est-ce qu'on vient d'ajouter ?**
- Chaque `pnpm add` télécharge une librairie.
- Les librairies sont stockées dans `node_modules/`.
- Elles sont référencées dans `package.json`.

## 📊 La Base de Données

### Qu'est-ce que WatermelonDB ?

C'est une base de données **relationnelle** pour téléphones mobiles.

**Analogie** : C'est comme un carnet avec plusieurs pages, où chaque page a une liste d'informations.

### Les Tables (Les Pages du Carnet)

#### 1. **WARS** (Les Domaines)

```typescript
// Structure d'une Guerre
{
  id: "uuid-unique",
  title: "Finances",           // Nom du domaine
  icon: "💰",                   // Emoji
  color: "#81ecff",            // Couleur néon
  type: "FINANCE",             // Type (enum)
  createdAt: "2026-04-08T...", // Date de création
  updatedAt: "2026-04-08T...",
}
```

**Exemples de Guerres** :
- Finance
- Santé & Physique
- Professionnel & Éducatif
- Spirituel & Mental
- Relationnel & Social
- Loisirs & Détente

#### 2. **BATTLES** (Les Objectifs)

```typescript
// Structure d'une Bataille
{
  id: "uuid-unique",
  war_id: "uuid-war",           // Lien vers la Guerre parent
  title: "Créer un fonds d'urgence",
  description: "3 mois de salaire",
  deadline: "2026-12-31",       // Date limite
  status: "IN_PROGRESS",        // IN_PROGRESS, COMPLETED, FAILED
  priority: "HIGH",             // HIGH, MEDIUM, LOW
  createdAt: "2026-04-08T...",
  updatedAt: "2026-04-08T...",
}
```

#### 3. **ADVERSARIES** (Les Petites Tâches)

```typescript
// Structure d'un Adversaire
{
  id: "uuid-unique",
  battle_id: "uuid-battle",     // Lien vers la Bataille parent
  title: "Ajouter 5000 FCFA à mon épargne",
  frequency: "WEEKLY",          // DAILY, WEEKLY, MONTHLY, ONCE
  recurrence_days: [1, 3],      // Lundi (1), Mercredi (3) si WEEKLY
  scheduled_at: "2026-04-15T10:00:00",
  completed_at: null,           // null = pas encore complété
  status: "WON",                // WON, LOST, PENDING
  reminder: true,
  createdAt: "2026-04-08T...",
}
```

**Cas d'utilisation** :
- Tâche quotidienne (DAILY) : Sport chaque matin à 6h.
- Tâche hebdo (WEEKLY) : Appeler maman le dimanche.
- Tâche mensuelle (MONTHLY) : Payer les factures.
- Tâche unique (ONCE) : Denicher un job.

#### 4. **ACCOUNTS** (Les Comptes Financiers)

```typescript
// Structure d'un Compte
{
  id: "uuid-unique",
  name: "MTN MOMO",             // Nom du compte
  type: "MOBILE_MONEY",         // MOBILE_MONEY, CASH, BANK, WAVE
  balance: 50000.00,            // Solde actuel
  currency: "XOF",              // Devise
  createdAt: "2026-04-08T...",
}
```

**Exemples** :
- MTN MOMO (Solde actuel)
- Orange Money
- Liquide (Cash)
- Compte Bancaire
- Wave

#### 5. **TRANSACTIONS** (Les Dépenses & Revenus)

```typescript

{
  id: "uuid-unique",
  account_id: "uuid-account",   // Lien vers le compte
  amount: 2500.00,              // Montant
```

**Catégories de Dépenses** :
- FOOD (Nourriture)

#### 6. **BUDGETS** (Les Budgets Mensuels)


#### Code TypeScript à Écrire

```typescript
// src/services/auth.ts
import * as SecureStore from "expo-secure-store";
import * as LocalAuthentication from "expo-local-authentication";

export async function authenticate() {
  try {
    // Vérifier si biométrie est disponible
    const compatible = await LocalAuthentication.hasHardwareAsync();
    
    if (!compatible) {
      // Fallback: Code PIN
      return askForPIN();
    }

    // Demander FaceID/Empreinte
    const result = await LocalAuthentication.authenticateAsync({
      promptMessage: "Authentifiez-vous",
      fallbackLabel: "Utiliser le Code PIN",
      disableDeviceFallback: false,
    });

    if (result.success) {
      return true; // Authentification réussie
    } else {
      return false;
    }
  } catch (error) {
    console.error("Erreur d'authentification :", error);
    return false;
  }
}
```

```typescript
export async function getDayStats(date: Date) {
  // Récupérer les tâches d'aujourd'hui
  const adversaries = await db
    .get("adversaries")
    .query()
    .where("scheduled_at", gte, startOfDay(date))
    .where("scheduled_at", lte, endOfDay(date))
    .fetch();

  const completed = adversaries.filter((a) => a.status === "WON").length;
  const total = adversaries.length;
  const percentage = total > 0 ? Math.round((completed / total) * 100) : 0;

  return { completed, total, percentage };

export async function getAverageBalance() {

    .where("status", "!=", "WON")
```

```typescript
// src/services/finance.ts
import { db } from "./database";

export async function addTransaction(
  accountId: string,
  amount: number,
  category: string,
  description: string,
  type: "INCOME" | "EXPENSE"
) {
  const transactionsCollection = db.get("transactions");

  // Créer la transaction
  const transaction = await transactionsCollection.create((trans) => {
    trans.account_id = accountId;
    trans.amount = amount;
    trans.category = category;
    trans.description = description;
    trans.type = type;
    trans.timestamp = new Date().toISOString();
  });

  // Mettre à jour le solde du compte
  const account = await db.get("accounts").find(accountId);
  await account.update((acc) => {
    if (type === "EXPENSE") {
      acc.balance -= amount;
    } else {
      acc.balance += amount;
    }
  });

  return transaction;
}
```

```typescript
import { db } from "./database";

export async function createBattle(
  warId: string,
  title: string,
  description: string,
  deadline: Date,
  priority: "HIGH" | "MEDIUM" | "LOW" = "MEDIUM"
) {
  const battlesCollection = db.get("battles");

  const battle = await battlesCollection.create((battle) => {
    battle.war_id = warId;
    battle.title = title;
    battle.description = description;
    battle.deadline = deadline.toISOString();
    battle.status = "IN_PROGRESS";
    battle.priority = priority;
  });

  return battle;
}

export async function createAdversary(
  battleId: string,
  title: string,
  frequency: "DAILY" | "WEEKLY" | "MONTHLY" | "ONCE",
  recurrenceDays?: number[], // [0, 2, 4] = Lun, Mer, Ven
  firstScheduledDate?: Date
) {
  const adversariesCollection = db.get("adversaries");

  // Si WEEKLY, créer une instance pour chaque jour spécifié pour les 3 prochains mois
  if (frequency === "WEEKLY" && recurrenceDays) {
    const today = firstScheduledDate || new Date();
    const threeMonthsLater = new Date(today.getTime() + 90 * 24 * 60 * 60 * 1000);

    let date = new Date(today);
    while (date <= threeMonthsLater) {
      if (recurrenceDays.includes(date.getDay())) {
        await adversariesCollection.create((adv) => {
          adv.battle_id = battleId;
          adv.title = title;
          adv.frequency = frequency;
          adv.scheduled_at = date.toISOString();
          adv.status = "PENDING";
        });
      }
      date.setDate(date.getDate() + 1);
    }
  }
}
```

```typescript
// src/services/nlp.ts
export interface Intent {
  type: "FINANCE" | "PRODUCTIVITY" | "HEALTH" | "OTHER";
  action: string;
  params: Record<string, any>;
}

export function parseUserInput(userInput: string): Intent[] {
  const intents: Intent[] = [];

  // Regex pour détecter les dépenses
  const expenseRegex = /(?:dépens|paié|acheté|coûté).*?(\d+).*?(cash|momo|wave|bank)/i;
  const expenseMatch = userInput.match(expenseRegex);

  if (expenseMatch) {
    const amount = parseInt(expenseMatch[1]);
    const account = expenseMatch[2].toUpperCase();

    // Déduire la catégorie du texte
    let category = "CUSTOM";
    if (userInput.includes("coiffeur") || userInput.includes("salon"))
      category = "HEALTH_BEAUTY";
    if (userInput.includes("mange") || userInput.includes("restau"))
      category = "FOOD";
    if (userInput.includes("taxi") || userInput.includes("transport"))
      category = "TRANSPORT";

    intents.push({
      type: "FINANCE",
      action: "ADD_EXPENSE",
      params: { amount, account, category },
    });
  }

  // Regex pour détecter les tâches
  const taskRegex = /(?:rappelle|ajoute tâche|fais|apprend).*?([^.]+)/i;
  const taskMatch = userInput.match(taskRegex);

  if (taskMatch) {
    const taskTitle = taskMatch[1].trim();

    // Détecter l'heure si elle existe
    const timeRegex = /(\d{1,2}):?(\d{0,2})\s*(h|am|pm)?/i;
    const timeMatch = userInput.match(timeRegex);

    intents.push({
      type: "PRODUCTIVITY",
      action: "ADD_TASK",
      params: {
        title: taskTitle,
        scheduledTime: timeMatch ? timeMatch[0] : null,
      },
    });
  }

  return intents;
}
```

### Algorithme 1 : Calcul de la Progression Journalière

**Objectif** : Calculer quelle pourcentage de tâches ont été complétées aujourd'hui.

```typescript
// src/services/stats.ts
export async function calculateDayProgress(date: Date) {
  const startOfDay = new Date(date);
  startOfDay.setHours(0, 0, 0, 0);

  const endOfDay = new Date(date);
  endOfDay.setHours(23, 59, 59, 999);

  // Récupérer les Adversaires d'aujourd'hui
  const adversaries = await db
    .get("adversaries")
    .query()
    .where("scheduled_at", gte, startOfDay.toISOString())
    .where("scheduled_at", lte, endOfDay.toISOString())
    .fetch();

  const completed = adversaries.filter((a) => a.status === "WON").length;
  const total = adversaries.length;

  const percentage = total > 0 ? Math.round((completed / total) * 100) : 0;

  return { completed, total, percentage };
}
```

### Algorithme 2 : Génération Automatique des Récurrences

**Objectif** : Créer des instances de tâches pour X mois en fonction de la fréquence.

```typescript
// src/services/recurrence.ts
type Frequency = "DAILY" | "WEEKLY" | "MONTHLY" | "ONCE";

export async function generateRecurrenceInstances(
  adversaryTemplate: {
    battleId: string;
    title: string;
    frequency: Frequency;
    recurrenceDays?: number[]; // 0=Dimanche, 1=Lundi, etc.
    startDate: Date;
  },
  monthsInFuture: number = 3
) {
  const endDate = new Date(adversaryTemplate.startDate);
  endDate.setMonth(endDate.getMonth() + monthsInFuture);

  const instances: Array<{
    battleId: string;
    title: string;
    scheduledAt: string;
  }> = [];

  let currentDate = new Date(adversaryTemplate.startDate);

  while (currentDate <= endDate) {
    let shouldCreate = false;

    switch (adversaryTemplate.frequency) {
      case "DAILY":
        shouldCreate = true;
        break;

      case "WEEKLY":
        // Si c'est un jour de la semaine spécifié
        if (
          adversaryTemplate.recurrenceDays?.includes(currentDate.getDay())
        ) {
          shouldCreate = true;
        }
        break;

      case "MONTHLY":
        // Si c'est le même jour du mois
        if (currentDate.getDate() === adversaryTemplate.startDate.getDate()) {
          shouldCreate = true;
        }
        break;

      case "ONCE":
        // Créer une seule fois à la startDate
        if (currentDate.toDateString() === adversaryTemplate.startDate.toDateString()) {
          shouldCreate = true;
        }
        break;
    }

    if (shouldCreate) {
      instances.push({
        battleId: adversaryTemplate.battleId,
        title: adversaryTemplate.title,
        scheduledAt: currentDate.toISOString(),
      });
    }

    // Avancer d'un jour
    currentDate.setDate(currentDate.getDate() + 1);
  }

  return instances;
}
```

### Algorithme 3 : Réajustement Automatique des Tâches Non Complétées

**Objectif** : Reprogrammer les tâches du jour qui n'ont pas été complétées vers des créneaux libres demain.

```typescript
// src/services/rescheduling.ts
export async function attemptReschedule(targetDate: Date) {
  const today = new Date(targetDate);
  today.setHours(0, 0, 0, 0);

  const tomorrow = new Date(today);
  tomorrow.setDate(tomorrow.getDate() + 1);

  // 1. Récupérer les Adversaires d'aujourd'hui non complétés
  const uncompleted = await db
    .get("adversaries")
    .query()
    .where("scheduled_at", gte, today.toISOString())
    .where("scheduled_at", lt, tomorrow.toISOString()) // Uniquement aujourd'hui
    .where("status", "!=", "WON") // Pas complétés
    .fetch();

  if (uncompleted.length === 0) return; // Rien à faire

  // 2. Récupérer les TimeLogs de demain pour trouver les créneaux libres
  const tomorrowTimeLogs = await db
    .get("time_logs")
    .query()
    .where("date", "==", tomorrow.toISOString().split("T")[0])
    .fetch();

  // 3. Trouver les heures libres (0-23)
  const occupiedHours = new Set(tomorrowTimeLogs.map((log) => log.start_hour));
  const freeSlots: number[] = [];
  for (let hour = 9; hour <= 18; hour++) {
    if (!occupiedHours.has(hour)) {
      freeSlots.push(hour);
    }
  }

  // 4. Reprogrammer les tâches vers les créneaux libres
  const batch = db.batch();

  uncompleted.forEach((adversary, index) => {
    if (index < freeSlots.length) {
      const newHour = freeSlots[index];
      batch.prepareUpdate(adversary, (adv) => {
        const newDate = new Date(tomorrow);
        newDate.setHours(newHour, 0, 0, 0);
        adv.scheduled_at = newDate.toISOString();
        adv.status = "PENDING"; // Remise à 0
      });
    } else {
      // Pas assez de créneaux, marquer comme "LOST"
      batch.prepareUpdate(adversary, (adv) => {
        adv.status = "LOST";
      });
    }
  });

  await batch.commit();

  // 5. Afficher une modale à l'utilisateur
  if (uncompleted.length > 0) {
    showRescheduleAlert(uncompleted.length, freeSlots.length);
  }
}

function showRescheduleAlert(uncompleted: number, availableSlots: number) {
  const message =
    availableSlots > 0
      ? `Tu as perdu ${uncompleted} bataille(s). Je les ai reprogrammées demain.`
      : `Tu as perdu ${uncompleted} bataille(s). Pas assez de créneaux libres demain.`;

  // Afficher alert
}
```

### Algorithme 4 : Détection des Trous dans l'Emploi du Temps

**Objectif** : Toutes les heures, vérifier s'il y a une heure non planifiée et envoyer une notification.

```typescript
// src/services/notifications.ts
import * as Notifications from "expo-notifications";

export async function scheduleHourlyNotifications() {
  // Cette fonction s'exécute au démarrage de l'app
  // Elle crée des tâches horaires pour vérifier les trous

  for (let hour = 6; hour < 23; hour++) {
    // De 6h à 22h
    scheduleNotificationForHour(hour);
  }
}

async function scheduleNotificationForHour(pastHour: number) {
  const now = new Date();

  // Vérifier si ce passé-heure avait une activité
  const todayString = now.toISOString().split("T")[0];

  const timeLogs = await db
    .get("time_logs")
    .query()
    .where("date", "==", todayString)
    .where("start_hour", "==", pastHour)
    .fetch();

  if (timeLogs.length === 0) {
    // Aucune activité enregistrée → Envoyer notification
    await Notifications.scheduleNotificationAsync({
      content: {
        title: "Qu'as-tu fait cette heure ?",
        body: `De ${pastHour}h à ${pastHour + 1}h, je n'ai rien d'enregistré.`,
        data: { pastHour, todayString },
      },
      trigger: {
        hour: pastHour + 1,
        minute: 0,
        type: Notifications.SchedulableTriggerInputTypes.CALENDAR,
      },
    });
  }
}

// Quand l'utilisateur clique sur la notification
Notifications.addNotificationResponseListener((response) => {
  const { pastHour, todayString } = response.notification.request.content.data;

  // Afficher Bottom Sheet pour que l'utilisateur rentre l'activité
  openActivityBottomSheet(todayString, pastHour);
});
```
